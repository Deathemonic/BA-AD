# baad-shared

Shared types and runtime hooks for **Blue Archive - Asset Downloader**.

`baad-shared` contains the common data models, constants, platform/build enums, global HTTP client hook, and download observer traits used by `baad`, `baad-dm`, `baad-utils`.

## Install

```toml
[dependencies]
baad-shared = { git = "https://github.com/Deathemonic/BA-AD" }
```
